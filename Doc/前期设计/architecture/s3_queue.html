3. 无锁并发任务队列

3.1 消息结构

struct LogicMessage {
    uint32_t    sessionId;
    uint32_t    msgId;
    uint64_t    traceId;       // GateServer 生成，贯穿 Gate→World→DB
    uint64_t    clientTraceId;  // 客户端可选传入

    std::chrono::steady_clock::time_point recvTime;
};

3.2 队列设计

单 MPSC 队列，自实现（非第三方库）。多生产者（N 个网络线程 enqueue）→ 单消费者（1 个逻辑线程 batch drain）。

3.3 实现：基于链表节点的无锁 MPSC 队列

基于 Michael-Scott 无锁队列变体做单消费者优化。核心是原子 head/tail 指针 + 链表节点池。 DrainAll 时将整个链表"摘走"——原子地 swap head 和 null，零竞争地拿到整条链表然后反转顺序， 消费者一侧无需遍历链表。 

// MpscQueue.h — 自实现无锁 MPSC 队列

class MpscQueue {
public:
    struct Node {
        LogicMessage msg;
        std::atomic<Node*> next{nullptr};
    };

    MpscQueue() {
        // dummy 节点保证 head 始终非空，简化边界条件
        _head = _tail = new Node{};
    }

    // 生产者端（网络线程调用） — 无锁 enqueue
    void Enqueue(LogicMessage msg) {
        auto* node = new Node{std::move(msg), nullptr};
        auto* prev = _tail.exchange(node, std::memory_order_acq_rel);
        prev->next.store(node, std::memory_order_release);
    }

    // 消费者端（逻辑线程调用） — 批量 drain，O(1) 摘走整条链表
    void DrainAll(std::vector<LogicMessage>& out) {
        // 1. 原子地从 tail swap 一个新 dummy——排入队列的消息同时被"摘走"
        auto* newDummy = new Node{};
        auto* first = _head.load(std::memory_order_acquire);
        auto* last  = _tail.exchange(newDummy, std::memory_order_acq_rel);
        _head.store(newDummy, std::memory_order_release);

        // 2. 遍历从 first→next 到 last，取出所有消息
        auto* curr = first;
        while (curr != last) {
            auto* next = curr->next.load(std::memory_order_acquire);
            auto* old  = curr;
            out.push_back(std::move(old->msg));
            if (curr != first) delete curr;  // 保留 head dummy
            curr = next;
        }
        // 3. 释放旧的 head dummy（first）
        delete first;
    }

    size_t SizeApprox() const {
        return _count.load(std::memory_order_relaxed);
    }

private:
    std::atomic<Node*> _head;   // 消费者侧 (只读)
    std::atomic<Node*> _tail;   // 生产者侧 (atomic swap)
    std::atomic<size_t> _count{0};  // 近似计数 (不精确)
};

3.4 内存序与正确性

操作内存序保证
_tail.exchangeacq_rel保证生产者看到消费者对 linked list 的完整写入
next.storerelease保证消息内容在 node 被消费者看到之前已经完全写入
_head.loadacquire消费者对 head 的读取与 tail 的 exchange 配对
⚠ 容量限制：当前实现不对队列容量做限制。如果逻辑线程处理速度落后于网络线程入队速度， 队列会无限增长（内存耗尽）。生产环境应在 Enqueue 前检查 SizeApprox()， 超过阈值时丢弃低优先级消息或主动断开慢速连接。
