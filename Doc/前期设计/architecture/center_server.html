CenterServer · 跨服通信与服务发现

1. 定位

CenterServer 是分布式集群的服务协调中心。各 WorldServer 启动时注册自身， 定期心跳。CenterServer 维护全服玩家位置索引（哪个玩家在哪个 WorldServer）， 提供跨服消息路由（私聊/全服公告）。不做业务逻辑——所有业务逻辑在 WorldServer/SocialServer 中完成。

2. 服务注册与发现

2.1 注册流程

WorldServer 启动
  ├── 1. 从 server.toml 读取 [center] address
  ├── 2. TCP 连接 CenterServer
  ├── 3. 发送 REGISTER { serviceType: "world", serverId: "world_1", address: "10.0.0.5:8001", maxPlayers: 5000 }
  │       CenterServer 记录: serviceId → {type, address, maxPlayers, status=ONLINE}
  ├── 4. 每 5s 发送 HEARTBEAT
  │       CenterServer 超时 15s 无心跳 → 标记 OFFLINE → 通知其他 WorldServer
  └── 5. 优雅关闭时发送 DEREGISTER → CenterServer 立即移除

3.2 内部 RPC 协议

// 内部 RPC——5 种进程之间的通信
struct RpcHeader {
    uint32_t length;
    uint32_t msgType;       // RPC 消息类型
    uint64_t requestId;     // 请求追踪 ID（Req-Rsp 匹配）
};

enum class RpcMsgType : uint32_t {
    // 服务发现
    REGISTER_REQ       = 0x1000,  REGISTER_RSP       = 0x1001,
    HEARTBEAT_REQ      = 0x1002,  HEARTBEAT_RSP      = 0x1003,
    DEREGISTER_REQ     = 0x1004,

    // 路由转发
    FORWARD_MSG        = 0x2000,

    // 事件通知
    SERVICE_ONLINE_NTF = 0x3000,
    SERVICE_OFFLINE_NTF = 0x3001,
    BROADCAST_NTF      = 0x3002,
    PLAYER_ONLINE_NTF  = 0x3003,
    PLAYER_OFFLINE_NTF = 0x3004,

    // 查询
    QUERY_PLAYER_LOCATION_REQ = 0x4000,
    QUERY_PLAYER_LOCATION_RSP = 0x4001,
};

3.3 跨服私聊路由

WorldServer_A 玩家 A 发私聊给 WorldServer_B 玩家 B
  │
  ├── 1. World_A: ChatChannelMgr.SendWhisper → 本地未找到 B
  ├── 2. World_A → Center: QUERY_PLAYER_LOCATION_REQ { playerName: "B" }
  │     Center: _playerLocationIndex → { serviceId: "world_2" }
  ├── 3. World_A → Center: FORWARD_MSG { targetService:"world_2", payload }
  ├── 4. Center → World_B: FORWARD_MSG { payload }
  └── 5. World_B: 查本地 → 找到 B → SendToClient

如果 B 离线：Center 返回 "not found" → World_A 返回 "玩家不在线"

5. 玩家上线/下线

Player 登录 WorldServer_A
  ├── 1. World_A → Center: PLAYER_ONLINE_NTF { playerName, serviceId="world_1" }
  │     Center: _playerLocationIndex.RegisterPlayer(playerName, "world_1")
  ├── 2. Center → SocialServer: 更新好友在线状态
  └── 3. Player 断线/登出
        World_A → Center: PLAYER_OFFLINE_NTF → 从索引移除

6. 性能考量

场景RPC 频率延迟
心跳每 5s × N 个 WorldServer< 1ms（同机房 TCP）
跨服私聊按需（低频）1-2ms（A→Center→B 两跳）
玩家上下线每登录/登出一次< 1ms
全服公告运营触发（极低频）< 1ms（并行广播）
