1. 整体架构总览 · C2 多进程分布式

1.1 设计哲学

5 种独立进程，一步到位分布式架构。C++23 + EnTT ECS + DasLang 脚本 + PostgreSQL 持久化。 无状态 GateServer 做纯代理路由（零密钥、零加密、零 DB），WorldServer 隐藏在内网。 DB 访问通过各进程内置的 DBWorkerPool（共享 common 库组件），直连 PgBouncer。 不设独立 DBServer 进程——业界主流做法（TrinityCore / Mangos / 天堂2）。

1.2 进程拓扑

Client (公网)
  │
  ├── ① TLS ──────→ LoginServer (公网)      ───→ 签发 SessionToken
  │
  ├── ② TCP ──────→ GateServer × N (公网)   ───→ 读 SessionId 路由
  │                     │
  │                     │ 内部 TCP（内网）
  │                     ▼
  │                WorldServer × M (内网 ONLY)
  │                  │ AES-GCM 加解密
  │                  │ ECS + DasLang
  │                  │ DBWorkerPool → PgBouncer → PostgreSQL
  │                  │
  │                  ├──→ CenterServer (服务发现 / 跨服路由)
  │                  └──→ SocialServer (公会 / 邮件 / 拍卖行 / 匹配)

LoginServer ──→ PgBouncer → PostgreSQL   (验证账号、查封禁)
SocialServer ──→ PgBouncer → PostgreSQL  (公会/邮件/好友持久化)

1.3 WorldServer 内部线程模型

IOContextPool (N 线程, 接收 Gate/Center/Social 的内部 TCP 包)
  │ Round-Robin
  ▼
IO 线程 → 收包 → 验证 SessionToken → 解密 → Enqueue(LogicMessage)
                                                  │
                                          MPSC Queue (无锁)
                                                  │
                                          LogicThread (单线程)
                                            │ DrainAll → 消息分发
                                            │ ecs_stage "movement" → ecs_stage "combat" → ...
                                            │ ecs_stage "save" → DBWorkerPool.AsyncQuery(sql, callback)
                                            │ ecs_stage "replicate" → 加密 → Gate
                                            │
                                            │ ProcessDBCallbacks() → 回调 lambda 在 LogicThread 执行

DBWorkerPool (3-5 Worker 线程, 各持一个 libpq → PgBouncer 连接)
  │ 收 SQL → 执行 → 结果塞回 MPSC Queue → LogicThread 下次 Tick 取

1.4 进程列表

进程公网？进程数密钥核心职责
LoginServer✅ TLS1-2LSS + ECDH 私钥账号认证 · ECDH · SessionToken 签发
GateServer✅2-8无TCP 连接保持 · SessionId 路由 · DDoS 吸收
WorldServer❌ 内网1-16LSS + SessionKeyECS + DasLang · 加解密 · 场景 · 逻辑 · DBWorkerPool
CenterServer❌ 内网1（主备）无服务发现 · 跨服路由 · 玩家位置索引
SocialServer❌ 内网1-2无公会 · 聊天 · 好友 · 邮件 · 拍卖行 · 匹配 · DBWorkerPool
