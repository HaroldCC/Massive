11. 部署拓扑设计 · C2 方案（无状态 Gate 路由）

11.1 为什么是 C2

项目从一开始就是多进程分布式架构，不走单进程合一再拆分的演进路线。 直接部署 5 种独立进程。C2 的核心优势：GateServer 完全无状态（只读 SessionToken 明文段做 O(1) 路由）， 零密钥、零加密、零 DB——纯 TCP 代理。WorldServer 隐藏在内网，所有公网流量强制经过 Gate。

11.3 数据库连接拓扑

不设独立的 DBServer 进程。需要持久化的进程（WorldServer / SocialServer / LoginServer）各自内部持有 DBWorkerPool（共享的 common 库组件），直连 PgBouncer。这是业界主流做法（TrinityCore / Mangos / 天堂2）。 

WorldServer ──┐
              ├── DBWorkerPool (3-5 worker) ──→ PgBouncer:6432 ──→ PostgreSQL
SocialServer ─┤       ↑ 每个 worker 一个 libpq 连接
              │
LoginServer ──┘       (LoginServer 同步查，2-3 连接)
进程DB Worker 数到 PgBouncer 的连接数查询模式
WorldServer3-53-5异步回调：LogicThread 发 SQL → Worker 执行 → 结果回 LogicThread
SocialServer22异步回调（同上）
LoginServer0（同步）2-3同步阻塞：`SELECT` → 验证 → 返回（登录非高频，可同步）

11.4 客户端视角——两次 TCP 连接

Client
  │
  ├── ① TCP → LoginServer (TLS)
  │     MSG_LOGIN_AUTH_REQ {username, password, clientDHKey}
  │     MSG_LOGIN_AUTH_RSP {gateIPs: [...], sessionToken: <46 bytes>}
  │     断开
  │
  ├── ② TCP → GateServer
  │     首包: MSG_LOGIN_ENTER_WORLD_REQ {sessionId, sessionToken}
  │     后续: 所有业务消息 (MsgID + SessionId 明文, Body AES-GCM 加密)
  │
  └── ③ Gate 断路 → 选下一个 gateIP 重连 → WorldServer 通过 SessionToken 重新绑定

11.5 各进程对 IOContextPool 的使用

进程IOContextPool 连接方说明
LoginServer客户端 TCP（TLS）+ PgBouncer（libpq）短连接——登录完就断。IOContextPool 2-4 线程。
GateServer客户端 TCP + WorldServer 内部 TCP对客户端：长连接(10K+)。对 World：每 World 一条 TCP。
WorldServerGate 内部 TCP + CenterServer TCP + SocialServer TCP所有连接来自内网，不直接对公网。DBWorkerPool 的 libpq 连接不走 asio。
CenterServer各 WorldServer 注册+心跳 TCP低频小包。
SocialServer各 WorldServer 的 RPC TCP中频，小包。DBWorkerPool 走 libpq 直连 PgBouncer。

11.6 开发环境——本地全部进程

# 终端 1: PgBouncer（需要 PG 先启动）
pgbouncer config/pgbouncer.ini

# 终端 2: CenterServer
./CenterServer --config config/center.toml   # localhost:7000

# 终端 3: SocialServer
./SocialServer --config config/social.toml   # localhost:7001

# 终端 4-5: WorldServer (可起多个)
./WorldServer --config config/world_1.toml   # localhost:8001
./WorldServer --config config/world_2.toml   # localhost:8002

# 终端 6-7: GateServer (可起多个)
./GateServer --config config/gate_1.toml     # localhost:9000

# 终端 8: LoginServer
./LoginServer --config config/login.toml     # localhost:8443
