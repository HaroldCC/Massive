测试策略 · 三层金字塔

1. 概述

测试按成本/速度/真实性分层。底层覆盖逻辑核心，上层覆盖端到端流程。 不对序列化/网络进行 Mock——集成测试即真实收发包。

E2E 模拟测试 (最慢, 最少)
1000 虚拟客户端 → 登录 → 发移动请求 → 检查广播 → 登出
⬆ 50-100 个
集成测试 (中等)
Scene 加载 → ECS 操作 → 寻路 → DB 读写
⬆ 200-500 个
单元测试 (最快, 最多)
队列、时间轮、MsgID 分发、NavMesh、DirtyTracker

4. E2E 模拟测试

// TestClient.h — 虚拟客户端池
class TestClientPool {
public:
    struct Client {
        uint32_t sessionId;
        Entity playerEntity;
        Vector3 position;
        std::deque<std::vector<char>> receivedPackets;  // 服务器发给客户端的包
    };

    // 批量连接 N 个虚拟客户端
    void ConnectClients(int count);

    // 每个客户端发送移动请求
    void SendRandomMoveRequests();

    // 检查每个客户端收到的广播——验证 AOI + 差量复制
    void VerifyBroadcasts();

    auto& Clients() { return _clients; }

private:
    std::vector<Client> _clients;
    std::unique_ptr<asio::io_context> _testCtx;
};

// 测试用例
TEST_CASE("100 clients join world and move") {
    auto server = StartTestServer();  // 启动精简版服务器（无加密、无 PgBouncer）
    TestClientPool pool;
    pool.ConnectClients(100);
    for (int tick = 0; tick < 20; tick++) {
        server.Tick(std::chrono::milliseconds(50));
        for (auto& client : pool.Clients()) {
            VerifyReceivedPacketCount(client);  // 检查收到 AOI 广播
        }
        pool.SendRandomMoveRequests();
    }
}

5. 确定性保证

单线程逻辑层的最大优势：相同输入 + 相同初始状态 → 相同输出。这使得回放测试成为可能。

测试能力说明
回放测试 (Replay)录制所有入站消息（LogicMessage），重放时逐 Tick 比对输出——检测回归 bug。每天 CI 跑 10 分钟录制的生产流量。
混沌测试 (Chaos)随机发送非法消息、超长包、乱序包——验证服务器不崩溃（仅 ERROR 日志）。
内存泄漏检测每 100 Tick 检查进程 RSS 增长——回归检测。
