18. GM 指令系统

18.1 注册机制：DasLang 侧注册

GM 指令在 DasLang 脚本中注册，不需要改 C++ 或重启服务器。新增 GM 指令 = 在 gm.das 加 3 行 + 热重载。 

// gm.das — 所有 GM 指令集中注册
[export]
def InitGmCommands()
{
    // gm_add_level(playerId, amount)  → minLevel=3（仅开发GM）
    RegisterGmCommand("add_level", 3, @(callerId: uint32; args: array<string>) {
        let targetId = int(args[0])
        let amount   = int(args[1])
        ecs_edit(targetId) $(var cmp) { cmp.playerData.level += amount }
        return "player {targetId} level +{amount}"
    })

    // gm_spawn_monster(sceneId, monsterTypeId, x, y, z)
    RegisterGmCommand("spawn_monster", 3, @(callerId: uint32; args: array<string>) {
        let sceneId   = int(args[0])
        let monsterId = int(args[1])
        let x = float(args[2]); let y = float(args[3]); let z = float(args[4])
        let e = SpawnMonster(sceneId, monsterId, x, y, z)
        return "spawned monster {e}"
    })

    // gm_kick(playerId)  → minLevel=2（运营+）
    RegisterGmCommand("kick_player", 2, @(callerId: uint32; args: array<string>) {
        let targetId = int(args[0])
        GmKickPlayer(targetId)
        return "player {targetId} kicked"
    })
}

// Proto 定义
message GmCommandReq {
    string command = 1;              // 指令名 "add_level"
    repeated string args = 2;        // 参数列表 ["1001", "5"]
    uint64 clientTraceId = 3;        // 可选
}
message GmCommandRsp {
    uint32 errorCode = 1;            // 0=成功
    string message = 2;              // 返回给客户端的消息
}

// C++ 侧 — GM 指令分发
class GmCommandDispatcher {
public:
    struct Entry {
        int minLevel;
        TLambda<void, uint32_t, const std::vector<std::string>&, const TBlock<void, std::string>&> handler;
    };

    void Register(const std::string& name, int minLevel,
                  TLambda<...> handler) {
        _commands[name] = Entry{minLevel, handler};
    }

    void Dispatch(uint32_t callerId, const std::string& command,
                   const std::vector<std::string>& args,
                   const TBlock<void, std::string>& respond);

private:
    std::unordered_map<std::string, Entry> _commands;
};

18.3 权限分级

级别角色可用指令示例
0普通玩家/help, /time, /who
1客服/query_player, /view_log, /send_compensation
2运营/broadcast, /start_event, /reload_config
3开发 GM/add_level, /spawn_monster, /teleport, /reload_script, /restart_scene

权限检查在 C++ 桥接层统一执行——从 _accountToSession 查到 account 的 gmLevel， 小于 RegisterGmCommand 注册时指定的 minLevel 则拒绝执行。

18.5 安全与审计

机制实现
审计日志每条 GM 指令执行写 gm_audit_log 表：callerId, command, args, result, timestamp, sceneId, traceId。
速率限制每个 GM 账号每秒最多 5 条指令（token bucket）。超过限制返回"rate limited"。
IP 白名单GM 账号可绑定 IP 白名单（gm_accounts 表）。非白名单 IP 的 GM 登录直接拒绝。
敏感操作二次确认级别 3 指令（/ban_player, /restart_scene）需要 GM 客户端二次确认弹窗。

18.6 GM 账号管理

GM 权限存储在数据库 gm_accounts 表中：

CREATE TABLE gm_accounts (
    account_id  INT PRIMARY KEY,
    gm_level    INT NOT NULL DEFAULT 0,     // 0-3
    allowed_ips TEXT,                           // 逗号分隔白名单，NULL=不限制
    created_by  INT,
    created_at  TIMESTAMPTZ DEFAULT NOW()
);
